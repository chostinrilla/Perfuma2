# Perfumados - Guía de Proyecto

## Stack
- Frontend: HTML5, CSS y JavaScript vanilla (sin frameworks).

## Estilo y Reglas
- Mantener el diseño responsive y limpio.
- Las imágenes se cargan desde la ruta `Imagenes perfuma2/`.
- No modificar la estructura de navegación entre `index.html`, `catalogo.html` y `admin.html` a menos que se solicite.
